# PeriLoop Console: two-minute demo script

About 280 spoken words. Record on the hosted demo, logged in as `doctor`, with the fictional demo patients loaded.
Two versions of the 1:05 line are given: use (A) only if a real model is connected and `run_model_eval.js` has been run; otherwise use (B).
Do not say "validated", "safe" or "approved".

| Time | On screen | Say | Do |
|---|---|---|---|
| 0:00 to 0:15 | Today | "Around surgery, things are found and then not followed through: a blood result, a consent, a worried message at night. PeriLoop is a prototype that gives each one an owner and a written closure. Every patient here is fictional." | Start on Today. |
| 0:15 to 0:35 | A knee replacement patient: checklist | "Each patient gets a checklist from the pathway. Every item has an owner and a due day. A task closes only with written evidence, and a doctor's decision only by a doctor." | Open Fict TKR-04. Close one task with a note. |
| 0:35 to 0:50 | Same page: readings | "Staff enter readings. A haemoglobin of 7.4 after surgery raises a red flag with an owner." | Enter Hb 7.4, press Add. |
| 0:50 to 1:05 | Live view | "The patient has a private chat link, in English, Malay, Chinese or Arabic. Here is the patient, the pipeline and the staff panel together." | Open Live view. Type "my calf is hard, sore and bigger than the other one". |
| 1:05 to 1:25 | Live view: pipeline | (A) "Fixed rules run first. Then an AI check, which can raise urgency but never lower it, and never writes clinical advice." (B) "Fixed rules run first. An AI check that can only raise urgency is built in; it is switched off in this recording and has not yet been measured in this system." | Point at each pipeline step. |
| 1:25 to 1:40 | Live view: an emergency | "An emergency gets a fixed text with the emergency number, and an alert. The text never promises that someone will reply." | Type "I can't breathe and my chest hurts". Then show Alerts and press Acknowledge. |
| 1:40 to 2:00 | Rules page, then the evidence table in the brief | "The honest part. The rules and texts were drafted by an AI. I labelled 368 invented English messages myself, blind. All 155 I called emergencies raised an alert with the AI check on; the rules alone missed five. But 47 of them were told to call the clinic, not the emergency number. One clinician, one model, no real patients yet. So this needs sign-off and a pilot before any patient uses it." | Show the draft labels on Rules, then section 5 of the brief. |

## Shot list

1. Today (0:00).
2. Patient checklist, closing a task with evidence (0:15).
3. Reading entered, red flag appears (0:35).
4. Live view, same-day message (0:50).
5. Pipeline steps (1:05).
6. Emergency message, Alerts, Acknowledge (1:25).
7. Rules page drafts and the evidence table (1:40).

## Before recording

- Set the clinic phone, hours and emergency number in Settings (confirm the Abu Dhabi number first).
- Check each button label against the page; the labels above are from the build of 12 Nov 2026.
- If a clinician labelling run or a real-model run exists by then, replace the numbers in the last line with those and say who labelled.
